# Game Builds

Run both builds from one server:

```bash
npm install
npm start
```

Open `http://localhost:3000/` for the game selector, or use:

- `http://localhost:3000/poker/` for the Unity WebGL poker build
- `http://localhost:3000/21bliz/` for the React 21 Blitz build

Set a different port with `PORT=4000 npm start` when needed.
